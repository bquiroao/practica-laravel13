# Módulo Expediente médico electrónico base

Expediente clínico de cada paciente en el Sistema Hospitalario Integrado: un expediente por paciente y hospital, consulta solo con una relación de atención vigente y, entre hospitales, con consentimiento o acceso de emergencia justificado. Todo acceso queda auditado y el expediente nunca se borra.
