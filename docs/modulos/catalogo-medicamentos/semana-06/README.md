## Cómo presentar

Con la extensión **Marp for VS Code**: abrir `presentacion.md` y usar «Open Preview» o exportar a
PDF. Las imágenes se cargan con rutas relativas a esta carpeta (se comprobó que los tres `.png`
existen). El ajuste visual de cada diapositiva en Marp queda **por verificar** en tu equipo: no
se pudo instalar Marp en el entorno donde se preparó la entrega.
