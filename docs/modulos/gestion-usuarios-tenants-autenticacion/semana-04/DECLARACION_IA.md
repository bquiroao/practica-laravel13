# Declaración de uso de inteligencia artificial

Se utilizó un asistente de inteligencia artificial para extender el ejemplo de la Semana 3 con la entrada MVC y los adaptadores InMemory, estructurar la suite de contrato compartido entre adaptadores, redactar el documento de capas y el análisis del repositorio de datos compartido. La estudiante debe revisar el código, comprender las decisiones y validar el material antes de presentarlo.

El ejemplo usa SQLite en memoria y arrays; no es la base productiva. Los datos son ficticios y no se usaron credenciales reales. La integración con el repositorio central del HIS es una propuesta analizada sobre las migraciones existentes, no una conexión implementada.
