# Declaración de uso de inteligencia artificial

Se utilizó un asistente de inteligencia artificial para organizar el diseño de componentes, resumir las responsabilidades observadas en los archivos de Laravel y Vue, redactar contratos y preparar un prototipo aislado del caso de uso de autenticación. La autora debe verificar la fidelidad de las referencias, comprender el refactor propuesto y validar el material antes de presentarlo.

El prototipo utiliza dobles y no se conecta a usuarios reales, tenants reales, base de datos, JWT de producción ni servicios externos. La documentación diferencia el código inspeccionado, la propuesta y las verificaciones ejecutadas; no afirma que la aplicación integrada ya haya sido refactorizada.
