# Declaración de uso de IA - Semana 5

Se usó GitHub Copilot como apoyo para estructurar el contrato OpenAPI, los diagramas y la documentación de arquitectura y planificación.

- La autora debe revisar y aprobar decisiones de tenant, RBAC, credenciales, expiración y operación.

- El OpenAPI y el plan de issues son artefactos de diseño: no representan una API desplegada ni issues creados.
- No se generaron secretos, credenciales, hosts institucionales reales ni infraestructura de producción.
