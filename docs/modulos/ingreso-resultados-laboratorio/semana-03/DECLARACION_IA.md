# Declaración de uso de inteligencia artificial

Se utilizó un asistente de inteligencia artificial como apoyo para estructurar las capas del prototipo PHP, redactar el esquema PDO, elaborar pruebas deterministas y preparar las vistas C4/UML. La estudiante debe revisar el código y validar el flujo con los responsables del laboratorio. Los datos usados son ficticios; el prototipo no consulta órdenes reales, no valida resultados clínicamente y no sustituye los controles de seguridad o autorización institucionales.
