# Formato de hallazgo técnico

- ID: NP-RTF-___
- Fecha y autor de observación: pendiente.
- Línea base (commit exacto) y artefacto/ruta/símbolo: pendiente.
- Checklist relacionado y RF/RNF: pendiente.
- Categoría: dominio / contrato API / permisos / tenant / capacidades / sincronización / plataforma / dependencia.
- Tipo: defecto demostrado / riesgo / omisión documental / pregunta.
- Precondiciones y datos ficticios: pendiente.
- Pasos mínimos o fragmento de evidencia: pendiente.
- Resultado esperado: pendiente.
- Resultado observado: pendiente.
- Impacto y severidad propuesta: pendiente.
- Severidad ratificada por moderador/revisor: pendiente.
- Responsable de corrección: pendiente de aceptación.
- Acción acordada y fecha límite (Guatemala): pendiente.
- Estado: propuesto / confirmado / en corrección / listo para retest / cerrado / diferido aceptado.
- Commit de corrección y salida/captura del retest: pendiente.
- Revisor que verificó y fecha: pendiente.
- Riesgo residual y motivo de diferimiento, si aplica: pendiente.

Cerrar solo con evidencia y validación del revisor; un defecto reproducido no es un defecto corregido.
