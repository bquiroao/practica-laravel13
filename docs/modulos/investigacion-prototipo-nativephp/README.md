# Módulo: Investigación y prototipo NativePHP para extensión móvil/escritorio

Evalúa la viabilidad de usar NativePHP como puente para una extensión móvil/escritorio del Sistema Hospitalario Integrado, con un prototipo acotado de un flujo HIS que se pueda ejecutar fuera del navegador y que mantenga integración con Laravel.
