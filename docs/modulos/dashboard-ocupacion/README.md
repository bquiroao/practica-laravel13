# Módulo Dashboard de ocupación hospitalaria

Tablero de ocupación de cada hospital del Sistema Hospitalario Integrado: consolida periódicamente cuántas camas hay disponibles, ocupadas, en mantenimiento e inactivas por sala, y lo muestra a quien gestiona las camas. Solo lee: los estados de cama los cambian el catálogo y admisión.
