# Declaración de uso de inteligencia artificial

Se utilizó un asistente de inteligencia artificial como apoyo para revisar el prototipo de recepción de muestras de Semana 3, organizar la propuesta de componentes, definir contratos conceptuales de entrada/salida y redactar la comparación antes/después del refactor. La estudiante debe validar la propuesta con recepción, laboratorio, responsables de custodia, privacidad y desarrollo. Las interfaces web, la verificación de órdenes y el registro de custodia se presentan como diseños pendientes, no como funcionalidades implementadas o probadas.
