# Declaración de uso de inteligencia artificial

Se utilizó un asistente de inteligencia artificial para estructurar el documento, organizar el ejemplo MVC/Repository, preparar pruebas para los adaptadores y redactar el análisis de integración compartida. La estudiante debe revisar el contenido, verificar los supuestos y comprender el código antes de presentarlo.

La entrega reutiliza el caso de uso y las reglas académicas de la Semana 2; no declara una Semana 3 inexistente ni integra el prototipo con Laravel o la base clínica. La base PDO probada es SQLite en memoria y utiliza datos ficticios. El análisis del repositorio central se basa en las migraciones del repositorio; la integración descrita es una propuesta, no una conexión ejecutada.
