# Declaración de uso de inteligencia artificial

Se utilizó un asistente de inteligencia artificial como apoyo para analizar el acoplamiento del código de la Semana 2, proponer los componentes y contratos, escribir la medición de acoplamiento, dibujar el diagrama y redactar la justificación. La estudiante debe verificar la comparación contra el código y poder defender cada decisión. La capa de presentación, el frontend y la correspondencia HTTP son propuestas no implementadas. Los datos son ficticios.
