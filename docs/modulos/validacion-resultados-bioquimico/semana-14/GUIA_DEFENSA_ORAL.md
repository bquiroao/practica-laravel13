# Guía de defensa oral — Semana 14

## Presentación breve

«Elaboré un plan SQA para el flujo de revisión, validación o rechazo de resultados por bioquímico. Incluye siete métricas con fórmula, meta, fuente, responsable y acción ante desviación; una matriz de riesgos; controles preventivos y detectivos; y un calendario diario, semanal, mensual y trimestral. Separé las metas operativas de los criterios clínicos: el plan no inventa rangos de referencia y mantiene la decisión bajo responsabilidad profesional.»

## Preguntas para explicar el plan

1. **¿Qué significa SQA aquí?** Asegurar mediante métricas, controles, revisión de evidencia y acciones correctivas que el flujo sea confiable, seguro y trazable.
2. **¿Los porcentajes son resultados medidos?** No. Son objetivos iniciales propuestos para el piloto. Deben aprobarse y contrastarse con una línea base de cuatro semanas.
3. **¿Qué significa la firma del bioquímico?** La relación auditable de identidad, hospital, versión, decisión y momento. No es una firma criptográfica.
4. **¿Cómo se maneja una versión que cambió?** El envío obsoleto debe terminar como conflicto, no como validación/rechazo; se recarga la versión actual y se revisa otra vez.
5. **¿Por qué no se define un umbral bioquímico?** Los intervalos dependen de la prueba y del procedimiento institucional; no se inventan ni reemplazan el juicio profesional.
6. **¿Qué se hace si falta una fuente de datos?** Se informa «sin datos», se asigna la instrumentación y no se registra como cumplimiento.
7. **¿Qué riesgos detienen el flujo?** Una decisión no autorizada, pérdida de trazabilidad o persistencia parcial; se contiene, se preserva evidencia y se reanuda tras verificación.

## Límites de la entrega

Es un plan académico propuesto, no evidencia de operación productiva ni política aprobada. La Semana 15 prueba el prototipo con dobles deterministas; no demuestra disponibilidad, seguridad desplegada, firma criptográfica, integración clínica ni cumplimiento regulatorio.
